## 1. Architectural Topology & Cold Plane Pipeline

```
┌────────────────────────────────────────────────────────────────────────┐
│                        COLD PLANE (Asynchronous)                       │
│                                                                        │
│   Vertex AI / Gemini Models:                                           │
│     - 09:15 EDT Macro Prior Gate: gemini-4-argon                       │
│     - Intraday Periodic (30m):   gemini-3.8-flash                     │
│     - 15:55 EDT EOD Synthesis:   gemini-4-argon                        │
│                                                                        │
│                      │ Writes atomic temp file                         │
│                      ▼                                                 │
│       state/control_signal.json.tmp (fsync)                           │
│                      │                                                 │
│                      ▼ os.replace                                      │
│           state/control_signal.json ◄────────────────────────┐        │
└──────────────────────────────────────────────────────────────┼─────────┘
                                                               │ Read (Fault-Tolerant)
┌──────────────────────────────────────────────────────────────┼─────────┐
│                        HOT LOOP (Real-Time)                  │         │
│                                                              │         │
│   strategies/regime_governor.py (AsymmetricHMMGovernor)      │         │
│     - Periodic call: ingest_cold_plane_signal() ─────────────┘         │
│     - Validates freshness: age <= 3600s                                │
│     - If circuit_breaker_override == True:                             │
│         * Posterior forced: [0.0, 0.0, 1.0] (Macro Shock)              │
│         * Target Satellite Weight W_sat forced to 0.00                 │
│     - If circuit_breaker_override == False:                            │
│         * Prior Bayesian blending: (1 - w)*pi + w*prior_probs          │
│     - Transitions logged atomically to state/trading_journal.db        │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.1 Schema Contract (`ControlSignalPayload`)

The cold plane signal dropped at `state/control_signal.json` adheres strictly to the following contract:

| Field | Type | Bounds / Allowed Values | Description |
| :--- | :--- | :--- | :--- |
| `timestamp_utc` | `string` | ISO-8601 UTC string (e.g., `"2026-10-26T13:15:00Z"`) | UTC timestamp of macro synthesis. Stale if age > 3,600s. |
| `model_version` | `string` | `"gemini-4-argon"`, `"gemini-3.8-flash"` | Vertex AI synthesis model tier. |
| `dominant_prior` | `string` | `"Goldilocks"`, `"Uncertainty"`, `"Macro Shock"` | Dominant regime classification. |
| `prior_probabilities` | `dict` | Keys: `"goldilocks"`, `"uncertainty"`, `"macro_shock"`, values $\in [0.0, 1.0]$, $\sum = 1.0 \pm 1e-3$ | Quantitative prior probability distribution. |
| `credit_spread_z_score` | `float` | Real number | Normalized hybrid credit spread anomaly score. |
| `nlp_sentiment_score` | `float` | $[-1.0, 1.0]$ | Clamped macroeconomic text sentiment score. |
| `satellite_target_weight` | `float` | $[0.0, 0.35]$ | Recommended 3x satellite allocation ceiling. |
| `circuit_breaker_override` | `bool` | `True`, `False` | Exogenous tail-risk circuit breaker trigger. |

#### Example Signal Payload (`state/control_signal.json`):
```json
{
  "timestamp_utc": "2026-10-26T13:15:00Z",
  "model_version": "gemini-4-argon",
  "dominant_prior": "Goldilocks",
  "prior_probabilities": {
    "goldilocks": 0.70,
    "uncertainty": 0.20,
    "macro_shock": 0.10
  },
  "credit_spread_z_score": 0.18,
  "nlp_sentiment_score": 0.42,
  "satellite_target_weight": 0.25,
  "circuit_breaker_override": false
}
```

### 1.2 Hot-Loop Ingestion Semantics

1. **Atomic Ingestion:** `read_control_signal` validates schema and staleness against `max_age_seconds` (default 3600.0s). Partial writes or torn reads are physically prevented by the `tmp -> fsync -> os.replace` atomic drop pattern.
2. **Circuit Breaker Override:** If `circuit_breaker_override is True`, `AsymmetricHMMGovernor` immediately forces state distribution to `[0.0, 0.0, 1.0]` (`Macro Shock`), trips `tail_risk_override_active = True`, zeroes $W_{\text{sat}}^*(t) = 0.0$, and logs the audit event to `state/trading_journal.db`.
3. **Continuous Prior Blending:** If `circuit_breaker_override is False`, the governor blends the current posterior with the cold plane prior using $w_{\text{blend}} = 0.35$:
   $$\pi_{\text{blended}} = (1 - w_{\text{blend}}) \cdot \pi(t) + w_{\text{blend}} \cdot \mathbf{p}_{\text{cold}}$$
   normalized to unit sum.
